## Описание

Сервер имитирует публичные сервисы измерения скорости (аналог speedtest.net), предоставляя возможность загрузки фейковых файлов размером от 1 МБ до 10 ГБ.

## Системные требования

- ОС: Windows Server 2008 R2 SP1 или новее
- Платформа: .NET Framework 4.8 (обязательно)
- Права доступа: Администратор (для запуска на порту 5000)

## Структура проекта

Проект разделен на модули для улучшения читаемости и поддерживаемости:

- `Program.cs` - Точка входа, оркестрация компонентов, логирование
- `BanManager.cs` - Управление банами клиентов и отслеживание запросов
- `NightModeService.cs` - Сервис ночного режима (01:00-06:00)
- `RequestHandler.cs` - Обработка HTTP-запросов, маршрутизация
- `index.html` - Главная страница с интерфейсом теста скорости
- `style.css` - Стили пользовательского интерфейса
- `script.js` - Клиентская логика теста скорости
- `suspicious_agents.txt` - Список подозрительных User-Agent
- `random_headers.txt` - Заголовки для рандомизации X-Powered-By

## Функционал

### Генерация файлов

Сервер генерирует файлы "на лету" без сохранения на диск:
- Начало файла содержит маркер: `ТЕСТ` (UTF-8)
- Конец файла содержит маркер: `ТЕСТ` (UTF-8)
- Остальное содержимое — нулевые байты

Доступные эндпоинты:
- `/download/100` - 100 МБ
- `/download/200` - 200 МБ
- `/download/500` - 500 МБ
- `/download/1000` - 1000 МБ (1 ГБ)
- `/download/N` - где N от 1 до 10240 МБ

### Система безопасности

#### Белый список URL
- `/` — главная страница
- `/favicon.ico` — иконка сайта
- `/updateBrowserInfo` — обновление информации о браузере
- `/748_dark` — секретный код разбана
- `/download/N` — скачивание файлов

#### Детектирование подозрительных запросов
Бан накладывается автоматически при любом подозрительном запросе:
- Подозрительном User-Agent (содержит ключевые слова из `suspicious_agents.txt`)
- Пустом User-Agent
- Accept: */* без Accept-Language
- Запросе вне белого списка

**Важно:** Второй шанс не предоставляется. Любой подозрительный запрос приводит к немедленной блокировке.

#### Срок блокировки
- Срок блокировки: 10 лет
- Файл хранения: `bans.ini`
- Формат: `IP_адрес|YYYY-MM-DD HH:mm:ss`

#### Секретный код разбана
Код `748_dark` может быть передан:
- В URL: `http://server:5000/748_dark`
- В Query String: `http://server:5000/?748_dark`
- В User-Agent: любой, содержащий `748_dark`

### Ночной режим

По умолчанию включён с 01:00 до 06:00:
- Сервер переходит в режим ожидания
- Обработка запросов приостанавливается
- Можно нажать **'Y'** в консоли для принудительного запуска

### Логирование

- Формат имени: `server_log_YYYY-MM-DD_HH-mm-ss.txt`
- Кодировка: UTF-8
- Создаётся новый файл при каждом запуске

### Статистика подключений

В заголовке окна приложения отображается количество подключений за последние 24 часа.
Обновление происходит каждые 30 секунд.

## Конфигурационные файлы

### suspicious_agents.txt
Список ключевых слов для детектирования ботов (поддерживает горячую перезагрузку).

### random_headers.txt
Список заголовков для рандомизации X-Powered-By.

### bans.ini
Файл хранит забаненные IP-адреса (создаётся автоматически).
